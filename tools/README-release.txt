BMS Suite
=========

Editing tools for Falcon BMS 4.38.

Start: BMSSuite.exe (the main menu). Choose the theater on the left, then a program.
User guide: BMS-Suite-User-Guide.pdf

  Programs\<program>   one folder per program; each keeps its settings, work folders and backups there
  Data\NaturalEarth    map data used by the programs

Needs the .NET 8 Desktop Runtime x64 (https://dotnet.microsoft.com/download/dotnet/8.0).
Keep this folder somewhere you can write to (for example C:\BMS Suite), not in Program Files.

Before a program writes into BMS it backs up every file it replaces (main menu → Backups; restore from the
program that made it). Close BMS before installing anything, and back up your BMS Data folder before you start.

The BMS Suite is free. If it helps you: https://ko-fi.com/danguard63 (also the button in the main menu).
